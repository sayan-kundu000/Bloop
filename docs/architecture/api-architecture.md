## 1. Executive API Overview

Bloop exposes a fully typed, asynchronous RESTful API over HTTPS. All routes are logically grouped by domain under the versioned namespace `/api/v1/`.

Interactive API documentation is automatically generated by FastAPI from Pydantic v2 models:
- **Swagger UI:** Accessible at `/docs`
- **ReDoc:** Accessible at `/redoc`
- **OpenAPI JSON:** Accessible at `/openapi.json`

## 2. Standard Response Envelope Model

All API responses strictly conform to a standardized JSON envelope structure to guarantee predictable parsing for client applications.

### 2.1 Success Envelope
Used for all successful operations (HTTP 200 OK, HTTP 201 Created):
```json
{
  "success": true,
  "data": {
    "id": 42,
    "name": "Sarah",
    "status": "active"
  }
}
```

### 2.2 Paginated Success Envelope
Used for paginated queries (e.g., Speech History):
```json
{
  "success": true,
  "data": [
    {
      "id": 101,
      "text": "Hello world",
      "voice_id": "sarah-voice-id",
      "created_at": "2026-09-14T12:00:00Z"
    }
  ],
  "pagination": {
    "page": 1,
    "page_size": 20,
    "total": 142,
    "total_pages": 8
  }
}
```

### 2.3 Error Envelope
Used for all failure modes (HTTP 4xx and 5xx):
```json
{
  "success": false,
  "error": {
    "code": "INVALID_TEXT_LENGTH",
    "message": "Text length must be between 1 and 2,500 characters.",
    "details": {
      "character_count": 3100,
      "limit": 2500
    }
  }
}
```

## 4. HTTP Status Code Mappings

| HTTP Code | Standard Meaning | Bloop Application Context |
| :--- | :--- | :--- |
| **200 OK** | Success | Standard GET/POST operations returning data. |
| **201 Created** | Resource Created | User registration, voice ingestion, favorite creation. |
| **206 Partial Content** | Byte Range Stream | Audio streaming (`GET /api/v1/tts/audio/{filename}`). |
| **400 Bad Request** | Business Validation Failed | Empty text, text > 2,500 chars, language/voice mismatch. |
| **401 Unauthorized** | Authentication Failed | Missing, invalid, or expired JWT Bearer token. |
| **403 Forbidden** | Authorization Denied | Attempting to access or delete another user's generation. |
| **404 Not Found** | Resource Absent | Generation, voice, or user ID not found. |
| **422 Unprocessable**| Schema Mismatch | Malformed JSON, missing required Pydantic fields. |
| **429 Too Many Requests**| Rate Limit | Burst limit exceeded on TTS or Quantum execution. |
| **502 / 503 Gateway** | Provider Down | ElevenLabs API unreachable, timeout, or quota exceeded. |
| **500 Internal Error**| Simulation Failure | Unhandled Qiskit/PennyLane exception (safely enclosed). |

## 5. Rate Limiting Strategy

To prevent API abuse and cost overruns on commercial TTS synthesis:
- **TTS Generation (`POST /api/v1/tts`):** Restricted to **10 requests per minute per user**.
- **Quantum Execution (`POST /api/v1/quantum/*`):** Restricted to **15 requests per minute per user** to protect CPU resources.
- **Authentication (`POST /api/v1/auth/*`):** Restricted to **5 login attempts per minute per IP** to prevent brute-force attacks.
- **Read Operations (`GET /history`, `GET /voices`):** Generously limited to **60 requests per minute**.
